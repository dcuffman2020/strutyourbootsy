# Tournament Armory: custom theme, contestant perspective, turn clock

- **Theme...** is available to the raid leader in live registration and to the practice host. Practice's theme setup step also opens it. The editor trims spaces and accepts a bounded 48-character name in the current alpha's plain-text format. Nothing is sent before Start; the accepted name is carried in the existing theme reveal. Random selection remains available. This does not implement the full theme catalog, saved custom-theme library, or live multi-round theme assignment.
- **View as** switches the local practice screen to a fictional contestant's view of the same round and clocks. This is read-only; use **Host view** to advance. Participants see the current and next contestants only. It sends no raid traffic.
- **Runway timer** is a separate pre-start setting: 0:30, 1:00, 2:00 (default), 3:00, or 5:00 per contestant. Begin Runway starts the first turn. Next Contestant resets the countdown for the next turn; expiry never advances automatically. Practice pause freezes the remaining time. The shared leader-authored deadline is included in schema-4 runway snapshots so missed messages catch up to the same clock. All live testers must use this version.

Lua 5.1 and 5.4 tests cover: custom name validation and secrecy until Start, authorized settings, six-client shared clock, no auto-advance, missed-next recovery, default and changed durations, practice perspective state continuity, pause/resume, and no practice traffic. Retail appearance and live transport still require a test in WoW.
